# 검수 범위

개인 환경의 원본 로그와 화면 캡처는 공개 자료에 포함하지 않습니다.

## 앱 동작

30개 모양, 두 창 크기, 상세 목록 및 세 아이콘 크기의 240개 네이티브 화면 조합을 검사합니다. 선택·스크롤·긴 한글 및 이모지 이름·전체 이름 툴팁·색 대비, 새 프로세스의 설정 복원, 연속 변경의 마지막 설정 저장을 확인합니다. 기존 파일 조작·드롭 데이터·접근 거부·이름 표시 회귀 검사도 유지합니다.

네이티브 검사는 화면에 표시하지 않는 AppKit 객체와 임시 파일·DB를 사용합니다. 운영체제에 키보드·마우스 이벤트를 보내거나 실제 네이티브 드래그 세션을 시작하지 않습니다. 실제 입력 지연이나 모든 Mac의 동작을 이 검사로 보증하지 않습니다.

## 배포 경계

- 공개할 파일을 개별 허용 목록으로 지정하고 Git의 검토된 내용과 대조합니다.
- 새 소스 사본을 동결해 빌드하며 빌드 전후 파일 해시와 실제 Cargo 출력 실행 파일을 연결합니다.
- 새 앱 폴더를 구성하고 허용되지 않은 파일·링크·메타데이터를 거부합니다.
- 개인 환경 경로와 지정 비공개 값, 알려진 인증 정보 형식을 원문과 일부 인코딩 형태에서 검사합니다.
- PNG/ICNS의 렌더링 데이터와 비필수 메타데이터를 구분합니다. 검토되지 않은 이미지 인코딩을 거부합니다.
- ZIP의 전체 바이트를 정해진 생성 형식과 비교해 중앙 디렉터리·로컬 헤더·추가 데이터·권한·시간·파일 내용을 검사합니다.
- 실패한 후보를 공개하지 않으며 예전 ZIP으로 자동 대체하지 않습니다.
- 공개용 Git 저장소는 이전 비공개 기록을 복사하지 않은 독립된 새 이력으로 구성합니다.
- 게시 전후 저장소 참조, 자동 소스 ZIP, 릴리즈 파일 및 익명 다운로드 바이트를 검토한 결과와 대조합니다.

GitHub나 제3자가 과거에 받은 사본의 회수까지 기술적으로 보장할 수는 없습니다. 실제 배포 검수의 결론은 검사한 파일과 시점, 적용한 규칙의 범위에 한정합니다.
