# 개인정보와 공개 자료

이 문서는 앱의 데이터 사용과 배포 범위를 설명합니다. 모든 환경에서 정보 노출이 절대 불가능하다는 보증은 아닙니다.

## 앱이 이 Mac에 저장하는 정보

설정, 탭, 즐겨찾기, 최근 폴더와 서버 주소, 기억한 폴더 접근 정보, 파일 작업·되돌리기 기록을 사용자 Application Support의 Rust Explorer 폴더에 저장합니다. SQLite 파일은 해당 사용자만 읽고 쓸 수 있도록 생성합니다. 작업 기록 화면은 최근 100개를 표시하지만, 이것이 DB 보관 개수나 자동 삭제 기한을 의미하지는 않습니다.

최근 폴더는 최대 20개, 최근 서버는 최대 10개를 관리합니다. 서버 주소에 포함된 비밀번호·인증 정보는 거부하며 로그인은 macOS가 처리합니다. 기억한 폴더 접근 정보는 앱의 폴더 접근 설정에서 지울 수 있습니다. 전체 디스크 접근과 F2 호환 권한은 선택 사항입니다.

검토한 코드에는 별도의 분석·광고·사용 통계 전송 클라이언트가 없습니다. 사용자가 요청한 서버 연결·AirDrop·Bluetooth·기본 앱 열기나 macOS 프레임워크의 통신까지 차단한다는 의미는 아닙니다. 진단용 metrics 옵션을 지정하면 로컬 성능 기록 파일을 생성합니다.

## 공개 소스와 배포 파일

공개 파일 목록을 명시하고, 그 목록에 있는 검토된 소스만 새 디렉터리로 내보냅니다. 기존 Git 기록, 내부 인계·리뷰·원본 로그, 실제 사용자 설정, 개발 환경 스크린샷은 포함하지 않습니다. 실행 ZIP에는 정해진 앱 구성 파일만 포함합니다.

빌드 중 개발자 홈·작업 디렉터리를 중립 경로로 치환합니다. 배포 전에 실행 파일, 이미지 컨테이너, 압축 내부 파일과 메타데이터를 검사합니다. 불필요한 EXIF/ICC·AppleDouble·파일시스템 확장 속성은 포장에 포함하지 않습니다. 개인키는 별도 로컬 위치에서 서명에만 사용합니다.

패턴 검사는 알려진 형태의 값과 명시된 비공개 규칙에 한정됩니다. 파일 허용 목록, 동결 소스와 출력물 해시 대조, 수동·독립 검수, 압축 해제·서명 검증을 함께 사용합니다. GitHub 계정명은 공개 저장소 소유자 및 작성자로 표시됩니다.
